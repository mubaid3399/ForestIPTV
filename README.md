# ForestIPTV — Premium 4K & FHD IPTV Streaming Service

Official web application repository for **ForestIPTV** ([forestiptvfreetrial.online](https://forestiptvfreetrial.online/)).

---

## Features
- **High-Performance Streaming UI**: Built with React 19, Tailwind CSS v4, and Vite.
- **Fluid Micro-Interactions**: Optimized 60 FPS GSAP & ScrollTrigger entrance animations and timeline reveals.
- **Production-Grade SEO Suite**:
  - Dynamic canonical tags, Open Graph cards, and Twitter Cards (`summary_large_image`).
  - Google rich snippet schemas: `Organization`, `WebSite`, `Product`/`AggregateOffer`, `HowTo`, `ItemList`, and `FAQPage`.
  - Production `robots.txt`, XML `sitemap.xml`, and `site.webmanifest`.
- **Pages & Modules**:
  - **Home**: Hero device showcase, Why Choose Us, Pricing teaser, Cable comparison, and Free Trial FAQs.
  - **Pricing**: Comprehensive multi-year prepaid plans with instant activation modals and comparison calculators.
  - **Channels**: Categorized 25,000+ live channel search, category filters, and live sports package lineups.
  - **Setup Guide**: Interactive multi-device installation walkthroughs for Firestick, Smart TV, Android, Apple TV, PC, and MAG boxes.
  - **Contact**: 24/7 dedicated support desk with WhatsApp integration and quick ticket dispatch.
  - **Custom 404**: Clean, zero-SVG/zero-image typography error page.

---

## Tech Stack
- **Framework**: React 19, React Router v7
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP 3.15 with `@gsap/react` and `ScrollTrigger`
- **Icons**: Lucide React
- **Build Tool**: Vite 8

---

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
